Luminara — a travel poster for a place that does not exist: a lagoon city where the water glows teal at dusk, lit by the Lantern Spire and strings of lanterns over stilt houses. Drawn with PIL, no network, fully deterministic.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024×1024) to `/output` (or `$MAKEFUN_OUTPUT_DIR`).
